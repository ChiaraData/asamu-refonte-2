# Ajouter une photo à la photothèque

1. Déposez la photo dans ce dossier.
2. Ajoutez une entrée dans le tableau `$photoGallery` de `includes/config.php`.
3. Renseignez l'image, le texte alternatif, la catégorie, le titre et la description.

Un exemple complet est commenté directement dans `includes/config.php`.
